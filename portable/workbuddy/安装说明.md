# AI思维（ai-thinking）WorkBuddy 懒人包 · 3 分钟上手

配套书：《AI 时代的新生：AI 思维》 https://ai-era-new-life.vercel.app
开源仓库：https://github.com/htom78/ai-thinking

## 包里有什么
- `ai-thinking/SKILL.md`：技能本体（含 name、description）
- `ai-thinking/soul.md`：工作默认。始终生效，八步只在大任务时走。指向仓库根目录的正本，不要另改一份；zip 里打的是文件本身
- `ai-thinking/ledgers/`：预测账本 `predictions.csv`、规则账本 `rules.csv`（各含一行"示例"，用前删掉）
- `ai-thinking/templates/weekly-review.md`：每周复盘模板
- `ai-thinking/scripts/brier.py`：给预测打 Brier 分（只用 Python 标准库）
- `ai-thinking.zip`：只含技能文件夹的技能包，用来上传

账本、周复盘模板和 `scripts/brier.py` 的正本在仓库的 `portable/`（`ledgers/`、`templates/weekly-review.md`、`brier.py`）。本目录里这三处是指过去的链接，不要另改一份。zip 里打的是文件本身。

## 第 1 步：上传技能（约 1 分钟）
1. 打开 WorkBuddy，左侧边栏点「专家·技能·连接器」，选「技能」页签。
2. 点「添加技能」→「上传技能」，拖入或选择 `ai-thinking.zip`。
3. 在「已安装」里确认能看到 ai-thinking，并处于开启状态。

> 说明：WorkBuddy 官方文档只写了"选中本地技能包即可完成导入"，**没有写明技能包的具体格式**（zip 还是文件夹、SKILL.md 放在哪一层）。本包按通行的 SKILL.md 技能格式打包：zip 内顶层是 `ai-thinking/` 文件夹，里面是 `SKILL.md` 和 `soul.md`。这个格式还没验证，要等 Tom 实际上传一次才算数。如果上传失败，可试：①直接上传 `ai-thinking` 文件夹；②把 `ai-thinking` 文件夹里的内容（不含外层文件夹）重新压缩后上传。技能若只加载 `SKILL.md`，把 `soul.md` 再贴进智能体说明。

## 第 2 步：建一个工作空间放账本（约 30 秒）
在电脑上建一个文件夹，例如 `我的AI思维`，把 `ai-thinking/ledgers`、`templates`、`scripts` 三个文件夹复制进去，删掉两个 csv 里的"示例"行。之后对话和定时任务都选这个文件夹作为工作空间。

## 第 3 步：建「每周复盘」定时任务（约 1 分钟）
左侧导航「定时任务」→ 右上角「新建」（手动新建），填写：
- 名称：每周复盘
- 提示词：粘贴下面整段；在输入框底部点「+」添加技能 ai-thinking
- 工作空间：选第 2 步的文件夹
- 重复：每周（例如周日）；时间：例如 20:00
- 权限：默认权限（敏感操作需你确认，不在电脑前任务会停在等待确认）或完全访问权限（无人值守）。按需选择。
- 可选：打开「消息推送到企业微信」

**本地还是云端？** 账本是本机文件，**推荐本地任务**（执行时电脑需开着、客户端不能退出）。云端任务电脑关机也能跑，但官方文档写明云端沙箱无法访问本机文件、不能选工作空间、不支持推送企业微信，所以云端只适合"不读账本、只做提醒和提问"的简化复盘。

可直接粘贴的任务提示词：
```
用 ai-thinking 技能做本周复盘。
1. 读取工作区 ledgers/predictions.csv 和 ledgers/rules.csv，列出本周已到期但"结果"或"状态"还没填的行，逐条问我结果（一次问完，不要一条一条问）。
2. 运行 python3 scripts/brier.py ledgers/predictions.csv，报告平均 Brier 分数和校准情况，指出我在哪类事上高估或低估。
3. 按 templates/weekly-review.md 的结构生成本周复盘，保存为 reviews/复盘-YYYY-MM-DD.md。
4. 对每个目标判断：继续 / 调整 / 换方案 / 重新认识本质，并检查本周有没有"反复回头沟通细节"或"停留在任务层"的信号。
5. 只追加或更新账本行，不删除历史；最后给出下周唯一最重要的一步。
```
建好后先点卡片上的「运行」试跑一次，确认结果符合预期。

> 云端简化版提示词：`用 ai-thinking 技能做本周复盘：请我一次性列出本周到期的预测和规则及结果，帮我算 Brier 分数，按"结果对照判据 → 账本 → 本质检查 → 下周最重要一步"输出。`

## 第 4 步：第一次使用，粘贴这段
```
用 ai-thinking 技能，并遵守同目录的 soul.md（工作默认，始终生效；八步只在大任务时走）。
别一步一问，也别在分歧上猜。细节不问。只在分歧点一次问完最关键的 1–3 个问题，每个附上默认答案。需要拍板的事整理成一份决策单，一次给我。
先认清本质：问题在哪一层、现状为什么是这样（≥3 个解释带概率），压成几条规则一次给我确认。确认后由本质推出 10x 目标和判断标准，给我 N 个彼此根本不同的方案，每个单独想。淘汰后推荐一个。写明这件事上你是 L1、L2 还是 L3。交证据，没有证据的标未满足。能撤回的按级别做，撤不回的攒成一批给我确认。所有概率写进 ledgers/predictions.csv，学到的规则写进 ledgers/rules.csv。
我的问题是：（在这里写）
```

## 注意
- 积分：官方文档提示，复杂任务和复杂技能积分消耗通常较高。本技能流程较长，建议日常小事不必调用。
- 记忆：WorkBuddy 的记忆是自动从对话中提取的摘要，不能精确保存账本，所以账本务必以工作区文件为准。
- 安全：本技能只包含说明文字、模板和一个本地打分脚本，不联网、不调用第三方。
